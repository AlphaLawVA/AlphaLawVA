# RAG 검색·생성 모델 비교 요약

계약서 검토·특약 생성에 쓰는 법령 검색 설정과 생성 모델의 비교 기록이다.
결과는 후보 비교이며 최종 결정이 아니다(`docs/RAG_AND_EVALUATION.md`).
원본 결과는 `local_data/rag_eval/`(git 제외)에 있다.

## 1. 법령 검색 설정 비교 (완료, 호출 비용 없음)

- 도구: `python -m ml.evaluation.rag_eval.retrieval_eval --dataset <정답 jsonl> --device cpu`
- 데이터: 법령 검색 정답 50문항(`statute_retrieval_v01_50_approved.jsonl`), 관련도 2 이상을 정답으로 본다.
- 조건: BGE-M3, 청킹 `article_with_overflow_split_v01`, 후보 깊이 50, LLM 호출 0회.
- 검증: dense 수치(Recall@5 46.7%, Recall@10 61.5%, MRR 0.593)가 기존 승인 평가(`statute-50-v01-initial`)와 일치한다.
- 실행 기록: `local_data/rag_eval/retrieval/run-003/` (config.json, results.json, summary.md)

| 방식 | Recall@3 | Recall@5 | Recall@10 | nDCG@10 |
|---|---:|---:|---:|---:|
| **dense (현재 서비스)** | **37.3%** | **46.7%** | **61.5%** | **0.535** |
| RRF 하이브리드 (dense+BM25, `search_many_hybrid`) | 16.4% | 27.4% | 43.9% | 0.334 |
| RRF + 2-gram BM25 | 29.0% | 37.0% | 50.1% | 0.415 |
| 가중합 BM25 0.1 + 2-gram | 24.0% | 29.5% | 35.5% | 0.308 |
| 가중합 BM25 0.8 (논문 최적값) | 1.5% | 2.0% | 4.5% | 0.052 |
| BM25 단독 / 2-gram BM25 단독 | 1.5% / 13.2% | 2.0% / 18.1% | 4.5% / 25.5% | 0.052 / 0.211 |

dense 대비 차이는 모든 하이브리드·BM25 변형에서 95% 신뢰구간이 0 아래이다(질문 단위 bootstrap).

### 해석

- 이 데이터에서는 **dense 단독이 가장 높다.** 논문의 "BM25+dense가 최고"는 재현되지 않았다.
- BM25가 낮은 원인은 서비스 BM25가 공백 단위 단어를 토큰으로 쓰기 때문으로 보인다("전입신고를"과 "전입신고"가 다른 토큰). 글자 2-gram으로 바꾸면 Recall@10이 4.5%에서 25.5%로 오르지만 dense에는 못 미친다. 형태소 분석을 쓴 BM25는 아직 비교하지 않았다.
- 논문은 도메인·데이터(민사 판례 QA, 파인튜닝한 E5)가 달라 그대로 이식할 수 없다.
- 서비스 최소 유사도(0.35)는 이 50문항에서 **아무것도 걸러내지 않는다**(0.25·0.5도 동일, 빈 결과 0%). 근거가 약한 질문에서 "근거 없음"으로 빠지는 장치는 사실상 작동하지 않을 수 있다. 무관한 질문(negative set)으로 별도 검증이 필요하다.
- 상위 3개에 앞뒤 청크를 붙이면 Recall이 37.3%에서 42.0%로 오르지만 컨텍스트가 평균 8.6개로 커진다.
- `search_many_hybrid`가 반환하는 유사도는 RRF 점수(약 0.03)라 서비스의 최소 유사도(0.35)를 그대로 쓰면 전부 걸러진다. 서비스가 하이브리드로 바뀔 때 함께 점검해야 한다.

### 한계

- 정답 50문항은 일반 사용자 질문 스타일이며 계약서 항목 질의와 분포가 다르다.
- 임베딩 선정에 쓴 같은 50문항이므로 가중치를 이 데이터에서 고르면 과적합한다. α 0.1·0.2는 탐색용이다.
- 법령 청크만 평가했다. 판례는 별도 비교가 필요하다.

## 2. 생성 모델 비교 (미실행)

계획만 확정했다. 유료 호출은 모델별로 승인받은 뒤 실행한다.

| 항목 | 내용 |
|---|---|
| 기준선 | `gemini-3.5-flash-lite` (입력 $0.30 / 출력 $2.50, 1M 토큰당) |
| 상위 기준 | `gemini-3.8-flash` (도입가 $0.75/$3.75, 2027-01-01부터 $1.50/$7.50) |
| 제외 | `gemini-2.5-flash-lite`(종료 보고 있음), `gemini-3.5-flash`(폐기) |
| 미정 | GPT·Claude 후보(모델명·단가 확인 전, 키·어댑터 필요) |
| 합격선(사전 설정) | 하네스 규칙 실패 0, 항목 반환 100%, 법적 결론 단정·없는 조문 인용 0, faithfulness 목표치는 첫 측정 전 합의 |
| 지표 | 규칙 채점, faithfulness·answer relevancy(판정 LLM), 근거 recall·precision(정답 라벨), 비용·지연 |
| 사람 검토 | 표본 검토 필수(자동 지표는 법리 뉘앙스를 못 본다) |
| 단가 출처 | <https://ai.google.dev/gemini-api/docs/pricing> (2026-11-06 확인, 3.6 Flash 단가는 원문 재확인 필요) |
