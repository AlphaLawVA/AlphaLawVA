# OCR 데이터 처리 정책 v0.1

## 적용 범위

이 정책은 계약서 단독 OCR 업로드 경로에 적용한다. 실제 서비스 공개 전에는
개인정보 처리방침과 해외 이전 동의 문구를 법률·보안 검토로 확정해야 한다.

## 보관과 전송

| 데이터 | 처리 목적 | 보관 정책 |
| --- | --- | --- |
| 업로드 PDF·이미지 | OCR 초안 생성 | 요청 처리 중 임시 파일만 사용하고 응답 전 삭제 |
| Document AI 원문 JSON·좌표 | 필드 추출 | 응답 생성 뒤 서버·DB에 저장하지 않음 |
| 브라우저 OCR 초안·미리보기 | 사용자 원문 대조 | 탭 세션 동안만 보관하고 검토 요청 성공 시 삭제 |
| 사용자 확정 계약·등본 스냅샷 | 계약서 검토·내용증명 입력 | MySQL 사용 시 AES-256-GCM 암호문으로 저장 |

현재 스냅샷 삭제·보관기간 자동 만료와 사용자별 접근 제어는 인증·결과 저장
통합 단계에서 구현해야 한다. 이 기능이 없는 동안 실제 이용자 문서를 받지 않는다.

## 개인정보 최소화

- OCR 텍스트에서 주민등록번호, 전화번호, 라벨이 있는 계좌번호를 추출 직후 마스킹한다.
- LLM·RAG 검색 질의에는 주민등록번호, 전화번호, 계좌번호, 파일 URL, 좌표와
  OCR 신뢰도를 전달하지 않는다.
- 주소와 당사자명은 스냅샷에 암호화해 보관하되, 검색 질의에서는 역할 기반
  비식별 값으로 대체한다.

## 외부 처리 동의

Google Document AI를 선택한 사용자는 다음을 고지받고 명시적으로 동의해야 한다.

- 수탁·이전 대상: Google LLC
- 처리 위치: 미국 `us` 리전
- 전송 데이터: 사용자가 선택한 계약서 PDF
- 목적: OCR 텍스트와 좌표를 이용한 사용자 확인용 필드 초안 생성
- 보관: AlphaLawVA 서버는 요청 후 원본·원문 OCR을 저장하지 않음
- 거부: 동의를 거부할 수 있으며 이 경우 외부 OCR 기능은 이용할 수 없음

이 문서는 개발용 최소 정책이며 법률 자문이나 완성된 개인정보 처리방침이 아니다.
