# 판례 리랭커 20문항 비교 결과

## 결론

사전 기준인 `NDCG@5` 차이 0.02 이내이거나 주요 지표의 우승 모델이 엇갈리면
비등한 것으로 판단한다. BGE와 Qwen의 `NDCG@5` 차이는 0.018282이고, BGE는
`NDCG@5`와 `Recall@5`, Qwen은 `Precision@3`, `MRR@5`, Top3 평균에서 앞섰다.
따라서 두 모델은 비등한 최종 후보로 보고 A 문체 10문항 보조 평가가 필요하다.

KURE nano는 세 후보 중 가장 빠르고 메모리가 적었지만 Dense보다 `NDCG@5`와
`Precision@3`가 낮았다. 이번 품질 기준의 최종 후보에서는 제외한다.

## 실행 조건

- 평가셋: `reranker_goldset_subset_v01`, 유형별 20문항
- 문체 구성: `specific_life` 10문항, `legal_mixed` 10문항
- Dense 후보: 질문별 사건번호 중복 제거 판례 20건
- 리랭커 입력: 판례별 Dense 상위 청크 최대 3개
- 판례 점수: 입력 청크 중 최고 리랭커 점수
- 최대 입력 길이: 512
- 배치 크기: 8
- 장치: CPU
- 외부 LLM/API 호출: 0회

Qwen은 법률용어가 포함된 질문에서 강했지만 생활형 질문에서는 Dense와 BGE보다
낮았다. BGE는 두 문체에서 비교적 고르게 동작했다. 질문별 `NDCG@5` 최고 횟수는
동점 포함 Dense 5회, KURE 5회, BGE 7회, Qwen 6회였다.

## 속도 해석

CPU 기준으로 세 모델 모두 실시간 서비스 목표인 질문당 P95 1.5초를 넘었다.
KURE도 14초가 걸렸고, BGE는 약 28초, Qwen은 약 56초였다. 최종 모델을 고른 뒤에는
후보 판례 수와 판례별 청크 수를 줄이거나 가속 장치를 사용하는 별도 최적화가 필요하다.
