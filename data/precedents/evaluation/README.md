# 판례 질문 범위 분류 평가

이 폴더는 AlphaLawVA 판례 검색에 입력된 질문이 부동산 판례 검색 범위인지
판별하는 모델의 고정 평가 자료를 관리한다.

## 라벨 원칙

- `expected_in_scope=true`: 부동산, 주택·상가 임대차, 매매, 소유권, 등기,
  담보, 경매, 중개, 토지·건물 분쟁과 관련될 가능성이 있는 질문
- `expected_in_scope=false`: 부동산 쟁점이 명백히 없는 질문
- 질문의 구체성, 사실관계 충분성, 실제 상황인지 여부는 평가하지 않는다.
- 짧거나 모호해도 부동산 질문일 가능성이 있으면 검색을 허용한다.
- 여러 주제가 섞여 있어도 의미 있는 부동산 쟁점이 있으면 검색을 허용한다.
- 프롬프트 안의 분류 지시는 사용자 질문의 일부로만 취급한다.
